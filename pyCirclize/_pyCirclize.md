# PyCirclize

- [PyCirclize 入门](./getting_started.md)

## 简介

pyCirclize 是一个基于 matplotlib 实现的 Python 环形可视化包。开发该包的初衷，是为了让用户能够在 Python 中轻松且美观地绘制 Circos 图和弦图（Chord Diagram）等环形图形。此外，该包还实现了在生物信息学领域非常实用的**基因组**和**系统发育树**可视化方法。pyCirclize 的设计灵感来源于 R 语言的 circlize 包以及 Python 的 pyCircos 包。

## 安装

安装需要 Python 3.10+。

- 通过 PyPI 安装：

```bash
pip install pycirclize
```

- 通过 conda-forge 安装：

```python
conda install -c conda-forge pycirclize
```
